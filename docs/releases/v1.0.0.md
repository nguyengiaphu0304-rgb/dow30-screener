# dow30-screener v1.0.0

The first portfolio-ready release turns the original exploratory scripts into an installable,
offline-verifiable equity-research toolkit with explicit data and information boundaries.

## Included

- fail-closed provenance, OHLCV, benchmark and point-in-time membership validation
- integrity-checked snapshot cache with bounded retries and explicit stale fallback
- MIT-licensed project-authored synthetic fixture and deterministic quality report
- typed corporate-action and survivorship disclosures
- leakage-resistant expanding-window evaluation
- benchmark and equal-weight baselines with explicit transaction costs
- seeded bootstrap uncertainty and predeclared sensitivity scenarios
- stable, checksum-bound demo report generated by `dow30-screener-demo`
- Python 3.11/3.12 CI, strict typing, packaging and dependency audit

## Verification

Run the commands in the README and compare a regenerated report with
`docs/demo/walk-forward-report.json`. The release tag must point to the commit that passed all CI
jobs. See `docs/release-checklist.md` for checks performed and checks intentionally not claimed.

## Limitations

The bundled data is synthetic. No licensed historical Dow universe or price history ships with this
release. Delistings, symbol changes, taxes, real calendars, serial dependence and vendor corrections
are not empirically validated. Results are test evidence only, not returns, alpha, financial advice
or production-trading evidence.
